# Lyric (Лирика) — неофициальный клиент ЭПОС

Исходный код кроссплатформенного приложения **«Лирика»** — альтернативного клиента для системы «ЭПОС Образование» Пермского края. Проект написан на **Flutter** и поддерживает Android, Linux и Windows.

> **Готовые сборки для Android** доступны в отдельном репозитории:  
> [**makaYtech/lyric_apk**](https://github.com/makaYtech/lyric_apk) — там же публикуются релизы и автообновления.

---

## Что это и для кого

**«Лирика»** — это дополнительный инструмент для учеников и их родителей, которые ежедневно пользуются электронным дневником ЭПОС. Приложение показывает расписание, оценки, домашние задания и профиль ученика в более удобном и быстром виде, чем мобильный веб-интерфейс.

**Для кого:**
- Для тех, кто хочет открывать дневник с телефона за пару секунд, а не через браузер.
- Для тех, кому не хватает функциональности официального мобильного приложения ЭПОС.
- Для пользователей, которые ценят офлайн-доступ к расписанию и оценкам.

**Чем не является:**
- Это **не** официальный продукт ЭПОС Пермского края (`edu-epos.permkrai.ru`) и не его замена.
- Приложение работает только с данными, которые пользователь получает при собственной авторизации через официальный механизм ЭПОС (Госуслуги / ЕСИА). Оно не использует закрытые API, обходы авторизации или скрытые эндпоинты.

## Возможности

- **Профиль ученика** — ФИО, класс, профиль обучения, список учителей с предметами, кабинетами и нагрузкой. Локальные аватарки.
- **Оценки** — по предметам и периодам, подсветка среднего балла, детали по каждой оценке и история изменений.
- **Расписание** — на любую неделю учебного года с учётом звонков, пар и окон. Режим правок: перенос, объединение/разъединение пар, перестановка, удаление с возможностью отката.
- **Домашние задания** — группировка по дню выдачи или дедлайну, вложения от учителя, возможность прикрепить свою работу.
- **Кроссплатформенность** — сборки для Android, Linux и Windows (десктопные версии находятся в активной разработке).
- **Автообновления** (в Android-сборках) — приложение само проверяет новые версии и предлагает обновиться.

## Технологии и структура

- **Фреймворк:** Flutter (Dart)
- **Платформы:** Android, Linux, Windows
- **Основные каталоги:**
  - `lib/` — бизнес-логика, экраны, виджеты, сетевой слой
  - `android/` — нативная часть для Android
  - `linux/` и `windows/` — платформенные обёртки для десктопа
  - `assets/` — ресурсы (иконки, шрифты и т.п.)
  - `test/` — тесты

Проект пишется одним автором. Архитектура, сетевой слой, работа с локальной базой, парсинг ответов API и логика расписания написаны вручную. ИИ-ассистенты привлекались точечно для второстепенных задач (визуальная вёрстка, шаблонные виджеты, рутинные модели данных).

## Сборка из исходников

### Требования
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (стабильная версия)
- Для Android: Android SDK и настроенный эмулятор или устройство
- Для Linux: зависимости Flutter для Linux (GTK, CMake, Ninja)
- Для Windows: Visual Studio с компонентами C++ и инструменты сборки

### Команды

```bash
# Клонировать репозиторий
git clone https://github.com/makaYtech/lyric.git
cd lyric

# Установить зависимости
flutter pub get

# Запустить на подключённом устройстве или эмуляторе
flutter run

# Собрать APK для Android (release)
flutter build apk --release

# Собрать для Linux
flutter build linux --release

# Собрать для Windows
flutter build windows --release
